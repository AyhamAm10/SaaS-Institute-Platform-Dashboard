# admin-dashboard

Next 16 + Mantine staff dashboard for the institute platform (Arabic, RTL).

- Workspace entry and protocol: `../CLAUDE.md`
- Rules (binding): `docs/rules/core.md`
- Feature and behavior docs: `../docs/INDEX.md`
- Shared UI components: `src/components/controllers/README.md`

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000, needs the backend running
```

Checks: `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`.
